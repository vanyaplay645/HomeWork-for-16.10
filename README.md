# Source Control - встроенный Git-интерфейс в VS Code. 

Открывается комбинацией Ctrl+Shift+G или через иконку ветки в боковой панели.

Вкладка делится на три зоны: 
- Changes (изменения),
- Staged Changes (подготовленные к коммиту),
- поле ввода Commit message.

Рядом с файлами стоят маркеры: 
- M - изменён,
- A - добавлен,
- D - удалён,
- U - новый.

Типичный рабочий цикл выглядит так: пользователь вносит правки, нажимает + напротив нужных файлов (или Stage All), пишет сообщение коммита и жмёт галочку. Затем Sync Changes отправляет всё на удалённый репозиторий.

Клик по файлу открывает diff-редактор (сравнение версий бок о бок). Оттуда можно подготавливать или отменять отдельные блоки кода, а не весь файл целиком.

Ветки переключаются кликом по имени ветки в статус-баре внизу, там же создание новой ветки и переключение на неё (checkout).

При конфликтах слияния VS Code подсвечивает проблемные участки и предлагает кнопки: 
- Accept Current (принять текущую версию),
- Accept Incoming (принять входящую версию),
- Accept Both (принять обе версии)
- Compare Changes (сравнить изменения).
Для сложных случаев есть трёхпанельный merge editor.

Отмена изменений работает на нескольких уровнях: Discard Changes откатывает незакоммиченные правки, Undo Last Commit отменяет последний коммит, а для уже отправленных коммитов используется revert - он создаёт новый коммит с обратными изменениями, не переписывая историю.

График коммитов (Graph) показывает историю ветвлений наглядно и помогает ориентироваться в структуре проекта.
